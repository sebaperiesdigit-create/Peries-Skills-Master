# Glossary

Definitions of all technical terms used during onboarding.

## A

**API (Application Programming Interface)**
A way for different software programs to talk to each other. Like a phone line between two apps.

**Argument**
Information you pass to a skill when you invoke it. Example: `/generate-report sales` — "sales" is the argument.

## C

**CLI (Command-Line Interface)**
A text-based way to interact with your computer. You type commands instead of clicking buttons.

**CLAUDE.md**
A special file in your project that contains rules Claude always follows. Think of it as the company handbook for AI.

**Connector**
See MCP Server. A bridge between Claude and an external tool.

## D

**Database**
A structured collection of data. Like a very organized spreadsheet that many programs can access.

## F

**Frontmatter**
The configuration section at the top of a skill file (between the `---` lines). Contains metadata like name, description, and settings.

## G

**Git**
A version control system that tracks changes to files. Like "undo" for your entire project, but better.

**GitHub**
A website where Git projects are stored and shared. Like Google Drive for code.

## H

**Hook**
An automatic action that runs before or after a skill does something. Like a security guard checking IDs at the door.

## I

**Invoke**
To start or call a skill. You invoke a skill by typing its slash command or describing what you need.

## J

**JSON**
A format for storing and sharing data. Looks like this: `{"name": "John", "age": 30}`

## L

**Local**
On your own computer, not on the internet or a server.

## M

**MCP (Model Context Protocol)**
A standard way for AI to connect to external tools and data sources. The bridge between Claude and your company's systems.

**MCP Server**
A program that runs on your computer or network, providing data to Claude through the MCP protocol. Like a translator between Claude and your database.

## O

**Onboarding**
The process of learning how to use a new system or tool. What you're doing right now.

**Output**
What Claude produces — text responses, files, commands, or visual content.

## P

**Pipeline**
A series of steps that happen in order. Like an assembly line for data.

**PR (Pull Request)**
A proposal to add changes to a project. Like submitting a document for review before it's officially added.

**Project**
Your work folder containing code, files, and configurations. The thing you're working on.

## Q

**Query**
A request for data from a database. Like asking a librarian for specific books.

## S

**Session**
A single conversation with Claude. Starts when you begin talking, ends when you close the chat.

**Skill**
A reusable set of instructions that tells Claude how to handle a specific task. Like a recipe for AI.

**Slash command**
A shortcut to invoke a skill. Example: `/start`, `/generate-report`. Type `/` to see available commands.

**SOP (Standard Operating Procedure)**
A step-by-step instructions for doing a specific task. Skills are SOPs for Claude.

## T

**Template**
A pre-made format you can fill in. Like a form with blanks to complete.

**Tool**
Something Claude can use to do work — read files, run commands, search the web, etc.

## U

**UUID (Universally Unique Identifier)**
A long string of characters that identifies something uniquely. Like a fingerprint for data.

## V

**Version control**
A system for tracking changes to files over time. Git is the most common version control system.

## W

**Workflow**
A sequence of steps to complete a task. The seven-layer architecture is our workflow for AI requests.
